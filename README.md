# Recetas de Mamá - Tienda online

Tienda online desarrollada con React para la venta de productos de pastelería preparados por **Recetas de Mamá**. El proyecto busca ofrecer una experiencia sencilla para explorar los productos disponibles y realizar compras.

## Tecnologías utilizadas

- React
- JavaScript
- HTML y CSS
- Vite

## Instalación y ejecución

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/SoyYuii/RecetasdeMama-tiendaonlineREACT.git
   ```
2. Ingresar a la carpeta del proyecto:
   ```bash
   cd Recetasdemama-tiendaonline
   ```
3. Instalar las dependencias:
   ```bash
   npm install
   ```
4. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abrir en el navegador la dirección local que indique la terminal (habitualmente `http://localhost:5173/`).

**Requisito:** tener instalado Node.js y npm.
